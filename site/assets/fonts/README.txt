Drop the CC Wild Words Roman font file here.

Expected filename (any ONE of these — the @font-face in styles.css tries them in order):
  cc-wild-words.woff2   (preferred — smallest, best for web)
  cc-wild-words.woff
  cc-wild-words.ttf
  cc-wild-words.otf

If your file has a different name, just rename it to one of the above.
If you only have a .ttf/.otf, that works — but converting to .woff2 first
(e.g. https://cloudconvert.com/ttf-to-woff2) will load noticeably faster.

This must be a file you have a license to use. CC Wild Words is a
commercial Comicraft font; self-hosting an unlicensed copy on a public
site is a licensing risk.
