Project · WCM-Q · Ongoing

Agentic AI for Clinical Workflows

Multi-step reasoning with tools, not a single prompt — agents that check the retrieval first.

Role
AI Research Specialist · WCM-Q
Stack
LangChain · LangGraph · Azure OpenAI · Agentic RAG
Year
2024 — Present
Status
Research → integration

The problem. Real clinical questions are multi-step: retrieve, cross-check, then answer. A single LLM call collapses all of that into one guess.

The approach. AI agents built with LangChain and LangGraph for dynamic multi-step reasoning, with retrieval and other tools the agent can call within an Agentic RAG workflow.

Multi-step reasoning with tool use, inside an Agentic RAG workflow.

What was hard. Designing the agent so it converges. Tool-using agents can take any number of steps to reach an answer, and the tradeoff between depth and cost has to be made explicit.

What shipped. An agent architecture for clinical workflows with multi-step reasoning and tool use, designed around Agentic RAG patterns.

What this changes. Treating retrieval as a tool the agent can invoke (and re-invoke) — rather than a one-shot context dump — opens up workflows a single LLM call can't reach.

Ongoing research at Weill Cornell Medicine — Qatar. Internal evaluation.
